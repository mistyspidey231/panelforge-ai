# PanelForge AI

An AI-powered story and manhwa creation studio. The first featured project is **The God Beneath My Shadow**, an original dark fantasy manhwa.

## Current prototype

- Project dashboard and series overview
- Story bible with synopsis, worldbuilding, power system and canon notes
- Character bible for six principal characters
- Eight-arc chapter roadmap and chapter selection
- Panel studio with editable image prompts and copy-to-clipboard
- Vertical-scroll reader preview with the opening of Chapter 1

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Next integrations

The current interface is a front-end prototype. AI image generation, persistent project storage, authentication, and production chapter artwork still need provider credentials and backend wiring. The preview art is intentionally illustrative placeholder artwork, not generated comic panels.

## Stack

Next.js 15, React 19, TypeScript, Lucide icons, custom CSS.
